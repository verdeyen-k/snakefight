# 🐍 Snake Fight

Play it at https://verdeyen-k.github.io/snakefight/

2 to 8 snakes (red, orange, yellow, green, teal, blue, purple, pink) slither around the same field.
Crash into a wall or any snake (even yourself) and you're out. **Last snake standing wins!**

## Fruit

| Fruit | Grow |
|---|---|
| 🍎 Apple | +1 |
| 🍇 Grape | +2 |
| 🍊 Orange | +3 |
| 🍌 Banana | +4 |
| 🍉 Watermelon | +5 |

Bigger fruit is rarer. When a snake crashes, it turns into a trail of apples.

## Rules

- Your snake wears a 👑 so you can spot it.
- If two heads bump into each other, the longer snake survives. Same length? Both are out.
- After 75 seconds the walls start closing in, so nobody can hide forever.

## Ways to play

- **Practice:** you against 1 to 7 computer snakes.
- **Online:** one person creates a room, and 1 to 7 friends type the 4-letter code on their own device. Only real players, no computer snakes.

## Controls

Arrow keys or WASD. On a phone, swipe on the board or tap the arrow buttons.

Made with plain HTML and JavaScript. Online rooms use Firebase Realtime Database.
